# [Thực hành] Tạo Form Tìm Kiếm Google

## 1. Mục tiêu

Luyện tập tạo biểu mẫu HTML và gửi dữ liệu từ form lên server thông qua phương thức `GET`.

## 2. Yêu cầu bài thực hành

- Tạo một trang web HTML cơ bản.
- Xây dựng form tìm kiếm gồm:
  - Một ô nhập từ khóa (`input type="text"`).
  - Một nút tìm kiếm (`button type="submit"`).
- Cấu hình form gửi dữ liệu đến Google Search:
  - `method="GET"`
  - `action="https://www.google.com.vn/search"`
  - `name="q"` cho ô nhập từ khóa.
- Kiểm tra chức năng tìm kiếm trên trình duyệt.

## 3. Nội dung thực hành

- Tạo và cấu hình HTML form.
- Gửi từ khóa tìm kiếm đến Google bằng phương thức `GET`.
- Thử thay đổi thuộc tính `method` và `action` để quan sát kết quả.
- Tìm hiểu cách thay đổi form để sử dụng công cụ tìm kiếm Bing.

## 4. Kết quả mong đợi

- Form hoạt động và chuyển hướng đến trang kết quả Google Search.
- Hiểu vai trò của các thuộc tính `action`, `method` và `name`.
- Biết cách gửi dữ liệu từ HTML form đến server.
